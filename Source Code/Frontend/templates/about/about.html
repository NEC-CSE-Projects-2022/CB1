About the Project

FuzzTabIDS is a twelve-stage hybrid Intrusion Detection System designed to handle high-dimensional, imbalanced, and noisy traffic data. Built on the CICIDS-2017 dataset, it integrates MRMR feature selection, TabNet deep learning, fuzzy logic thresholds, micro-corrections with Decision Trees and Random Forests, and a stacked ensemble with XGBoost refinement. This layered design improves accuracy, recall on rare attacks, and interpretability, making it a reliable choice for real-world network security.

Core Methodology

  1. Dataset preprocessing and cleanup (removing noise, handling imbalance).
  2. Feature reduction using Minimum Redundancy Maximum Relevance (MRMR).
  3. TabNet for interpretable deep learning on structured features.
  4. Fuzzy logic layer for adaptive decision thresholds under uncertainty.
  5. Correction modules (Decision Tree, Random Forest, XGBoost) for hard cases.
  6. Ensemble models with weighted voting and stacking for robust predictions.

Key Advantages

  1. Near-perfect accuracy on binary, 7-class, and 15-class tasks.
  2. Improved recall on minority attack classes.
  3. Interpretable predictions via TabNet attention masks.
  4. Adaptive correction of low-confidence cases.
  5. Resilience against imbalanced and noisy traffic data.
